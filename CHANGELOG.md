# Changelog

All notable changes to this project will be documented in this file.

## [1.1.3] - 2026-09-27

### Added
- Implemented a prominent Data Privacy Notice modal for the AI Assist feature to comply with Chrome Web Store policies.
- Added explicit user consent state tracking before allowing AI queries to be sent to external providers.
- Added a Privacy Policy & Data Collection section to the README.

### Fixed
- Fixed an issue where the extension might collect and send JSON schemas to AI providers without prior explicit user consent.
